You are an expert full-stack developer. Build a **Construction Expense Tracking Web App with an Interactive Dashboard**.

The goal is to help construction contractors track project expenses, receipts, and budgets across multiple job sites.

Use a **modern full-stack JavaScript stack**.

Recommended stack:

* Frontend: React (with Vite)
* Backend: Node.js + Express
* Database: PostgreSQL (or SQLite for local development)
* Charts: Chart.js or Recharts
* Styling: Tailwind CSS

The UI must be clean, mobile-friendly, and easy to use in the field.

---

APP NAME
BuildTrack – Construction Expense Manager

---

CORE FEATURES (MVP)

1. Authentication

* User signup
* Login
* Logout
* Basic role support (Admin, Manager, Worker)

2. Project Management
   Users can create and manage construction projects.

Project fields:

* id
* project_name
* description
* budget
* start_date
* status (active, completed, on_hold)

Users must be able to:

* create a project
* edit project details
* view project list

3. Expense Tracking

Users can log expenses tied to projects.

Expense fields:

* id
* project_id
* category
* amount
* vendor
* date
* notes
* receipt_image_url

Default categories:

* Materials
* Labor
* Fuel
* Equipment Rental
* Tools
* Permits
* Misc

Users must be able to:

* add an expense
* edit an expense
* delete an expense
* view all expenses

4. Receipt Upload

Allow users to upload a photo of a receipt when creating an expense.

Store images in a simple storage folder and save the path in the database.

5. Expense List Page

Display expenses in a table with filters:

Filters:

* project
* category
* date range

Columns:
Date | Project | Category | Amount | Vendor | Notes

6. Interactive Dashboard

Create a dashboard page with:

A. Budget Overview

* total project budget
* total spent
* remaining budget
* progress bar

B. Charts

* Pie chart showing expenses by category
* Bar chart showing spending by project
* Line chart showing spending trend over time

C. Recent Expenses
Show the 5 most recent expenses.

7. Budget Tracking

Each project should track:

* total expenses
* remaining budget

Display a budget progress bar on the dashboard.

8. Export Data

Allow users to export expenses as CSV.
